# Discord Economy Bot

Bot economy Discord bergaya sederhana seperti bot economy populer.

## Fitur
- /balance
- /daily
- /work
- /give
- /leaderboard
- /slot
- /coinflip
- /mines
- /addmoney (admin)
- /removemoney (admin)
- SQLite database otomatis

Minigame tidak menggunakan taruhan Coin; slot, coinflip, dan mines memberi XP.

## Cara menjalankan
1. Install Python 3.11 atau lebih baru.
2. Buka terminal di folder bot.
3. Jalankan:
   pip install -r requirements.txt
4. Salin `.env.example` menjadi `.env`.
5. Isi `DISCORD_TOKEN` dengan token bot kamu.
6. Jalankan:
   python bot.py

Jangan pernah membagikan token bot kepada orang lain.
